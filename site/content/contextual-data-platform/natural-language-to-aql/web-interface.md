{{< tag "Agentic AI Suite" "Beta" >}}

{{< warning >}}
Natural Language to AQL was the previous version of the AQLizer and is deprecated
in favor of the new [AQLizer](../aqlizer/_index.md). Use the AQLizer to
generate and optimize AQL queries.
{{< /warning >}}

The web interface no longer offers Natural Language to AQL. The **AQLizer** tab
of the Query Editor now runs on the Reasoner service. To generate and optimize
queries there, see
[How to use the AQLizer in the web interface](../aqlizer/web-interface.md).

You can still call a running Natural Language to AQL service through its
[API](api-reference.md).
