description: >-
  _arangoexport_ is a client tool to export data to formats like JSON, JSON
  Lines (JSONL), CSV, and XML for consumption by third-party tools, using a
  command-line interface (CLI)
---
_arangoexport_ can export data to supported text formats from
[ArangoDB servers](../../arangodb-server/_index.md).

If you want to create backups, see [arangodump](../arangodump/_index.md)
instead.
