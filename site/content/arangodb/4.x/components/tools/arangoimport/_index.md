description: >-
  _arangoimport_ is a client tool to import data in JSON, CSV, and TSV format
  using a command-line interface (CLI)
---
_arangoimport_ can import supported text formats to
[ArangoDB servers](../../arangodb-server/_index.md).

If you want to restore backups, see [arangorestore](../arangorestore/_index.md)
instead.
